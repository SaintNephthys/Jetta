# JETTA

브라우저에서 실행하는 반응형 게임 모음입니다. 사칙연산 게임은 덧셈, 뺄셈, 곱셈, 나눗셈과 세 가지 난이도를 제공합니다. 화면 문구는 영어입니다.

게임 페이지에 진입하면 게임 유형 선택 창이 열립니다.

- **Question goal**: 문제 수를 1–200개로 지정하고 완료 시간을 측정합니다.
- **Time challenge**: 시간을 10–3,600초로 지정하고 제한 시간 동안 제출한 문제 수와 정답 수를 측정합니다. 앱이 백그라운드로 이동해도 시간은 계속 흐릅니다.

완료 후 정답률, 제출한 문제 수, 소요 시간, 문제당 평균 시간과 연산별·문제별 결과를 확인할 수 있습니다. 최근 완료 기록과 테마 설정은 해당 브라우저의 로컬 저장소에만 저장됩니다.

게임 화면은 데스크톱, 태블릿, 모바일, 폴더블의 좁은 커버 화면에 맞춰 배치됩니다. `VisualViewport`의 크기와 위치 변화를 반영해 소프트 키보드 위의 보이는 영역에 문제와 입력란을 배치하며, 안전 영역과 지원 브라우저의 폴더블 화면 분할 정보를 반영합니다. 매우 낮은 화면에서는 진행 막대를 숨기고 스크롤을 허용합니다. 키보드의 실제 동작은 기기와 브라우저에 따라 달라 실기기 확인이 필요합니다.

## 로컬 실행

프로젝트 루트에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. ES 모듈을 사용하므로 파일을 직접 여는 대신 로컬 서버를 사용하세요. 테스트는 Node.js 18 이상에서 `npm test`로 실행합니다. `tests/`의 Node.js 기본 테스트 러너가 문제 생성, 두 모드의 종료 조건, 시간 초과 및 빈 결과를 검증합니다. 패키지 설치나 빌드 과정은 필요하지 않습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 푸시합니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 **Deploy from a branch**로 선택합니다.
3. 사용할 브랜치와 **/(root)** 폴더를 선택하고 저장합니다.
4. 배포가 완료되면 Pages 설정에 표시되는 주소로 접속합니다.

모든 리소스 경로는 상대 경로이므로 프로젝트 저장소의 하위 경로에서도 동작합니다. 글꼴은 Google Fonts에서 불러오며, 사용할 수 없을 때는 기기 기본 글꼴로 표시됩니다.
