# 생각놀이터

서버 없이 브라우저에서 실행하는 반응형 게임 모음입니다. 첫 게임인 사칙연산 연습은 연산 종류, 난이도, 문제 수를 선택할 수 있으며 정답률과 연산별·문제별 결과를 보여줍니다. 최근 완료 기록은 해당 브라우저의 로컬 저장소에만 저장됩니다.

## 로컬 실행

프로젝트 루트에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다. ES 모듈을 사용하므로 파일을 직접 여는 대신 로컬 서버를 사용하세요. 테스트는 Node.js 18 이상에서 `npm test`로 실행합니다. 패키지 설치나 빌드 과정은 필요하지 않습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 푸시합니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 **Deploy from a branch**로 선택합니다.
3. 사용할 브랜치와 **/(root)** 폴더를 선택하고 저장합니다.
4. 배포가 완료되면 Pages 설정에 표시되는 주소로 접속합니다.

모든 리소스 경로는 상대 경로이므로 프로젝트 저장소의 하위 경로에서도 동작합니다. 글꼴은 Google Fonts에서 불러오며, 사용할 수 없을 때는 기기 기본 글꼴로 표시됩니다.
